    01 / ONTOLOGY AGENT

    让 Agent 用本体回答，而不是猜

    示例公司走本体推理；真实 A 股可按 6 位代码或简称查询公开行情与年报，再映射进同一套本体。 LLM key 只放在服务端环境变量里；GitHub Pages 上的静态页面永远不包含密钥。

    正在检查 Agent 服务…

    浏览器只连接公开 API；请求由服务端处理。

    KEY SAFETY

    静态页面没有 LLM_API_KEY，也不会向浏览器下发密钥。密钥由服务端在调用 LLM 时注入， 并受 CORS、频率限制与每日额度保护。

    部署与密钥配置 →

    05 / SKOS TAXONOMY

    行业、主题与风格，三套概念方案

    SKOS 把“分类”从类层次中解耦：行业可以多对多关联主题，主题又可以跨行业复用。多语言标签与定义让分类可被人和机器同时阅读。

    SKOS CONCEPT

    选择一个概念

    行业、主题与风格概念共享同一套 SKOS 标签、定义与关联机制。

    06 / SHORT-TERM & HOT MONEY

    短周期：先看情绪，再看资金与承接

    中长期看基本面，中短期看趋势、资金、题材和筹码。首板、连板、反包、炸板、龙虎榜、北向、两融和主题热度，被放进同一条判断链。

    01

    市场环境

    指数趋势、成交额、涨跌家数、炸板率与连板高度决定今天能不能做。

    02

    题材主线

    主题热度、政策/事件催化、龙头高度与板块扩散决定资金往哪里去。

    03

    个股承接

    首板时间、封单、竞价量比、龙虎榜游资净买与次日溢价决定个股强不强。

    04

    风控退出

    炸板、断板、量价背离、监管降温和 T+1 流动性决定什么时候退出。

    DRAGON-TIGER

    席位不是跟买名单

    先分营业部/机构，再买一卖一、游资机构是否混合；大游资齐聚可能是接力末端，不是无脑买点。

    AUCTION

    竞价先做预期，再看预期差

    9:15–9:20 可撤单，9:20–9:25 不可撤单；高开、量能与临近 9:25 的上抢要一起看。

    REVIEW

    复盘和账户诊断

    先看涨跌停、连板、炸板、主线和阶段；再拿交割单找选股、买入、卖出和回撤问题。

    情绪六阶段 启动发酵高潮结束反复冰点

            09 / ODRL POLICIES

            权限、禁止、义务，都能被机器检查

            ODRL 政策不是一段免责声明。它把“谁能对哪个资产做什么、在什么约束下、违反后怎么办”表达为可校验的规则。
